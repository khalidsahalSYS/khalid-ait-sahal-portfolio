# Khalid Ait Sahal — Online CV

A simple, responsive one-page online CV.

## Preview locally

Open `index.html` in a browser. The profile image is stored at `assets/profile.jpg`.

## Publish with GitHub Pages

In the repository settings, open **Pages**, select the `main` branch and `/ (root)` as the source, then save. GitHub Pages will provide the public site URL when deployment is ready.
